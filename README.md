# Ayense Works

Ayense Works, SOLIDWORKS kullanıcıları için Ayense tarafından geliştirilen yardımcı uygulamadır. Üretim hazırlığı, sac açınım, nesting, profil hesabı, malzeme listeleri ve teknik ofis süreçlerini tek çalışma alanında hızlandırır.

## İndirme

En güncel ve doğrulanmış kurulum paketini [Sürümler](https://github.com/kubilayonur/Ayense/releases/latest) sayfasından indirebilirsiniz.

- Web sitesi: https://ayense.com
- Ürün sayfası: https://ayense.com/ayense-works
- Destek: https://ayense.com/destek

SOLIDWORKS, Dassault Systèmes SolidWorks Corporation'ın tescilli markasıdır. Ayense Works bağımsız olarak geliştirilen bir yardımcı uygulamadır.
